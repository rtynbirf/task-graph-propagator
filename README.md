**Один алгоритм — все функции структуры графа задач.**
Ядро — пропагатор (функция Грина на графе):

```
K(v) = ν_v( φ(v) ⊕ Σ_{u→v} ε_uv(K(u)) )      — в полукольце S
```

## Вывод

1. Пропагатор = амплитуда дойти до вершины v — сумма по **всем путям** (фейнмановская):
   `K(v) = Σ_p Π_{e∈p} ε_e`.
2. Группировка путей по последнему ребру → `K = φ ⊕ ÂK` → `K = (1−Â)⁻¹φ`
   (резольвента, ряд Неймана, уравнение Дайсона).
3. На DAG ряд конечен → **одна проходка в порядке Кана = точное решение**.
   Порядок Кана — та же развёртка в булевом полукольце.

## Универсальная теорема

Пусть `K*(v) = Σ_{p: s⇝v} [p]` — универсальный пропагатор в свободном полукольце
путей. Тогда **всякая функция структуры есть гомоморфный образ K\***:
`F(v) = h(K*(v))`, h — единственный гомоморфизм полуколец
(индукция по порядку Кана ∎).

## Реестр: одно ядро → все функции структуры

| Полукольцо S | Функция структуры |
|---|---|
| (∨,∧) | достижимость · замыкание · K(v,v)=циклы |
| (max,+) | расписание E(v) · критический путь (запаздывающий K⁺) |
| (max,+) на Gᵀ | поздние сроки · резерв R=T−K⁺−K⁻+d (опережающий K⁻) |
| (min,+) | кратчайший маршрут |
| (+,×) | статсумма — число путей |
| (max,×) | надёжность · Viterbi-мировая линия |
| (max,min) | пропускная способность · узкое место |
| ℝ[z] | производящая функция: полное распределение длин путей |
| Нейман+β | циклический режим: стоячие амплитуды |

## Статистическая механика и управление

- **Тропический предел**: `(max,+) = lim_{β→∞} (1/β)·ln(+,×)` с весами e^{β·len} —
  критический путь есть основное состояние статсуммы; свободная энергия f(β) убывает.
- **Критичность**: `c(v) = n⁺(v)·n⁻(v)/N` — плотность мировых линий через событие,
  готовый градиент ∂T/∂d.
- **Крэшинг-контур**: ПРОПАГАТОР → градиент → сжатие → ПРОПАГАТОР до дедлайна;
  тупик жадного хода = нелокальность (нужно одновременное сжатие пары ветвей).

## Мировые практики, на которых стоит ядро (срез 2026-11-04)

- **GraphBLAS** (forum с 2013; C API v2.1.0 — финальный стандарт 22.12.2023;
  SuiteSparse:GraphBLAS, LAGraph, python-graphblas — «task graph» там канонический
  пример графа): идея «алгоритм графа = линейная алгебра в полукольце».
  Здесь — та же алгебра без матричного аппарата: разреженный матвек по слоям Кана
  эквивалентен проходке `sweep`.
- **Mohri (2002)**, «Semiring frameworks and algorithms for shortest-distance
  problems»: расстояния до фикспойнта в произвольном полукольце — один итерационный
  жанр (в доме — `pathsum` для циклов).
- **Radul & Sussman (2009)**, «The Art of the Propagator» (MIT CSAIL) и практический
  наследник ekmett/propagators (Haskell): ячейки с merge и покоем — тот же
  фикспойнт в инкрементальном жанре.
- **Клейни-алгебры и замыкание всех пар** (Höfner–Möller, Kleene algebra with
  tests): Флойд-Уоршалл в произвольном полукольце — один алгоритм на все пары.
- **CPM-практика 2026** (Asana «Critical path method 2026», PMI «Crash with
  confidence»): longest path, float/slack, schedule compression по cost slope —
  здесь это не отдельно, а следствия одного ядра (K⁺/K⁻/резерв/крэшинг-контур).

Ни одна из них не нужна как зависимость: всё — собственный труд на stdlib,
идеи приняты зерном (провенанс дома: «здесь нет ни байта чужого»).

## Контракт для мультиагентной среды

Единая точка входа — не менять сигнатуру:

```python
sweep(G, phi, semiring, eps=None, nu=None) -> (K, pred, order, cycles)
```

- `G` — TaskGraph (adj/cost/cap/dur/prob), `phi` — граничное возбуждение V→S,
- `eps(u,v,Ku)→S` — функтор ребра, `nu(v,x)→S` — функтор вершины,
- новые функции структуры = новый экземпляр `Semiring`, ядро не трогается.
